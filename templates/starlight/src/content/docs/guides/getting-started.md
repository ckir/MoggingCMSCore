This is a sample guide. Replace this page with yours.

Every page under `src/content/docs` is English text that MoggingCMS tracks. When you import the site, each page
becomes a document, and compiling asks the configured model for a draft in every target language.

Nothing is published until a person has reviewed the draft. Approved drafts go out in a release, and exporting writes
them back as Markdown files under `src/content/docs/de/` and `src/content/docs/zh-cn/`.
